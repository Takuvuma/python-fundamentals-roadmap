# Python → Data Structures & Algorithms Roadmap

Personal learning roadmap for going from zero Python to solid data structures
and algorithms fundamentals, with an eye toward IT support / cybersecurity /
SOC analyst roles.

## Why this order

Data structures and algorithms are concepts. You need a language to actually
build and reason about them, so Python fundamentals come first. Once syntax
is second nature, data structures and algorithms get layered in — using
Python as the implementation language.

## 01 — Python Fundamentals
Variables, control flow (`if`/`for`/`while`), functions, basic I/O. Goal:
write a script without looking up syntax every line. ~2-3 weeks of steady
practice.

## 02 — Core Data Types & Collections
Lists, dicts, sets, tuples, strings — in depth. How they work under the
hood, when to use each. This is the bridge into data structures, since
Python's built-ins are simplified data structures themselves.

## 03 — OOP & Modules
Basic classes/objects and structuring a script into reusable functions and
modules. Needed to implement data structures like linked lists or trees by
hand.

## 04 — Classic Data Structures
Stacks, queues, linked lists, trees, hash tables, graphs. Implement each by
hand once to understand them, then lean on Python's built-ins
(`dict`, `list`, `collections.deque`) for real work.

## 05 — Algorithms & Complexity
Sorting, searching, recursion, Big-O notation. Enough to reason about
efficiency and pass standard technical screens — not a full competitive-
programming grind.

## 06 — Apply It: Security Scripting
Use Python for what's actually relevant: parsing logs, automating
Wireshark/Snort output analysis, hitting APIs, small IAM/network automation
scripts.
